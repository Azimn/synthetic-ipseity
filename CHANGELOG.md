# Changelog

## 0.8.0 Palinode second-thought candidate, 2026-10-10

Added a compact, opt-in reflective-access gate over existing v0.7 provisional belief changes. A character may become aware of a prior change of mind only through host-attested, acquired and admitted cognitive input. Later recall of that reconsideration requires a real acknowledged subject-only outbox delivery plus separately attested memory acquisition. Append-only receipt tickets, subject/epoch checks, pre-ACK rejection, crash rollback and restart cases are tested. No automatic conversion of hidden bookkeeping into lived memory; no new independent architecture or consciousness claims.

## 0.7.0 provisional belief revisions, 2026-10-10

Preserves the v0.6 source-correction and retraction ledger while adding an append-only host-attested provisional belief position trail, active-evidence validation, atomic transaction integration, restart tests and additive SQLite schema upgrade from ledger 1 to 2. The reference subject renderer remains isolated from engineering-only revisions. No parallel ledger is introduced and no behavioral improvement has been claimed.

## 0.6.0 longitudinal epistemic ledger candidate, 2026-10-10

Introduced a character-agnostic append-only evidence history, materialized active source stances and topic identity, verified across-tick contradiction transitions, explicit correction and retraction observations, transactional cursor/ledger/outbox persistence, restart/failure injection, and independent tests. Claims are never promoted into objective truth by majority. Raw provenance remains engineer-only, and v0.1-v0.5 host APIs remain compatible. Host attestation, independent witness identity, semantic claim alignment, and real application bypass prevention remain unproven beyond the reference boundary.


## 0.5.0 epistemic source-monitor candidate, 2026-10-10

Added character-agnostic epistemic source monitor with host-attested evidence classification, typed source-to-observation adaptation, downgrade of unverified claimed lived memories, bounded qualitative recognition confidence, and explicit structured contradictions without unearned verdicts. Added adversarial source-monitor tests, durable restart integration, end-to-end diagnostic and evidence contract. This is a narrow structural source-monitoring mechanism, not semantic truth evaluation or proof of improved persona continuity.


## 0.4.0 renderer ingress candidate, 2026-10-10

Added first-person-only reference renderer port over the committed SQLite outbox, with isolated fake-model tests for raw-state exclusion, hostile external content, memory provenance, retries, restart recovery, and non-automatic memory writes. This covers the reference renderer handoff, not a universal guarantee that downstream hosts cannot bypass it.

## 0.3.0 durability candidate, 2026-10-10

Added character-independent SQLite durable host with atomic checkpoint/outbox commit, FIFO subject-only delivery leases, restart and uncertainty recovery, strict subject/epoch partitioning, duplicate source cursor rejection, corrupt checkpoint/outbox rejection, simulated crash injection, standalone diagnostic, crash matrix and adversarial tests. Not an exactly-once delivery guarantee; host-level renderer isolation and scientific continuity evidence remain pending.

## 0.2.0 integration candidate, 2026-10-10

Added character-agnostic restartable SyntheticIpseityOrgan with independently attested typed ingress, explicit body/world/memory/cognition/tool/self-perception channels, a strict monotonic epoch event cursor, denial receipts, immutable subject frames, engineer-only audit, integrity-checked portable checkpoints, and an optimistic two-phase preview/commit API. Extended bounded projectors for pain, hunger, fear, seen text, world objects, tool text, impulse, intention, concern, inference, imagination, dream, and later self-hearing. Added adversarial tests, an end-to-end offline diagnostic and a host integration contract. The v0.1 interface remains supported.

No downstream character repositories are modified. Functional contract tests are not evidence of psychological efficacy, consciousness or host-level no-bypass.

## 0.1.0 candidate, 2026-10-10

Initialized independent Synthetic Ipseity research repository, first-person subject-frame contract, deterministic host-attested projectors, bounded admission, engineer audit isolation, threat model, donor crosswalk, draft controlled experiment, reference diagnostics, and regression CI.

No downstream changes to Pretorius, DUCK, the laboratory, or other character projects. No consciousness or behavioral improvement claim.
