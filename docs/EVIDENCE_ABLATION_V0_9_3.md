# v0.9.3 Evidence Ablation: Is the classifier listening?

**Prospective registration before any v0.9.3 inference.** The real v0.9.2 96-probe run found extreme B/C answer-position preferences and zero changed choices when direct versus handoff contexts were swapped. That result is retained unchanged in results/FORMAT_CALIBRATION_REAL_2026_10_10.md. This NEW experiment tests whether answer choices respond to **changed evidence** rather than just changes in how the same evidence is represented.

## Locked design

Re-use exactly two source stems, C01 (contradiction) and C02 (corroboration), the C first-person control and the D organ-generated record, and the original two recipient models (SmolLM2-135M-Instruct and 360M-Instruct). The case content is already fixed in v0.9's CASES table.

Hold each question, A/B/C choices and their positions *identical* while only the record changes:

- **Original:** genuine source text from the v0.9 case.
- **Reversed:** the same topic, first witness, second witness and labels, but with the second witness's report polarity reversed. D is genuinely regenerated by the v0.8 Palinode organ from the new event, not hand-authored. This creates different ground truth on five dimensions (stance, evidence, noticed_change, recalls_notice and next_action). Source count remains both in either case.
- **Neutral:** a record explicitly containing no witness statements and no acquired belief or recollection. No true answer is assigned to this condition because several choices do not offer an unknown response. It serves only as a **position-prior negative control**.

Two stems × two arms × two recipient model identities × six questions × three evidence states = **144 real next-token logit comparisons**. This is an entirely direct-record instrument test, not a renderer handoff or a continuation study. No unrestricted text generation and no original six-field JSON rubric are used. Each letter must be one tokenizer token or the procedure fails.

## Preregistered decision metric

The **primary gate** is correct polarity reversal on the five fields where the truth changes. Credit only if BOTH original and reversed predictions match their independently constructed gold answers. If a model chooses the same letter regardless of the altered record, it receives zero for that paired field. We also report raw option-change rate, original accuracy, counterfactual accuracy, fraction differing from the neutral condition, per-item predictions/logits, and source token sizes.

A trivial letter-B-only strategy must fail the polarity reversal gate. A perfectly evidence-sensitive oracle must pass it, irrespective of the absolute letter position. These are tested with synthetic mock scorers before any real model is run; mock outputs are never reported as observations.

**Go/no-go:** If correct polarity reversal is effectively zero or very rare on both models, the forced-choice instrument is not demonstrating content sensitivity and must not be used to claim a Palinode cognitive benefit. Do not change the options to optimize scores on these same two observed stems. Instead add a separately preregistered larger (roughly 1B–2B) local instruction model capacity control and a broader balanced source set. If the instrument responds to evidence, test independent handoff retention with counterbalanced cases before any claim of cognitive-organ efficacy.

## Provenance and cost

The workflow uses standard free public-repository Ubuntu CPU runners and public Apache-2.0 model weights with exact model revisions logged. Full question manifest, content SHA hashes, each letter's raw logit, chosen letters, run duration and scored result are stored in GitHub Actions artifacts. No paid inference APIs, private Pretorius data or schedule. It has a 25-minute job timeout and no result is silently imputed after failures.

The original v0.9 strict six-field JSON results and v0.9.2 real logit-format calibration are not modified. This is **an instrument-responsiveness test, not a test of autonomous character continuity or subjective experience**.

## Completed real trial and gate decision

The first CPU trial [run #38095345440](https://github.com/Azimn/synthetic-ipseity/actions/runs/38095345440) produced **144/144** authentic rank-logit responses and a complete archived artifact. The preregistered correct-polarity-reversal gate **failed**: C/135M 0/10, D/135M 1/10, C/360M 0/10, D/360M 0/10. Choices were nearly identical under direct, polarity-reversed, and neutral evidence. [See raw-result provenance and complete negative findings](../results/EVIDENCE_ABLATION_REAL_2026_10_10.md). The original v0.9 and v0.9.2 scores remain unchanged. Follow-on runs are manual-only.
